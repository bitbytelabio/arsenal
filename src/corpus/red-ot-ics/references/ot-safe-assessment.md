# OT Security Assessment Safety Checklist

1. Scope of Authorization and Emergency Contacts  
2. Whether active probing / write operations are permitted (default: No)  
3. Maintenance windows and rollback plans  
4. Prioritize traffic mirroring over port scanning  
5. Immediately halt escalation and notify upon discovering high-severity risks  
6. Report differentiation: Remotely exploitable vs. Requires physical access  

Common protocol ports (for identification purposes only, not an exploitation manual): Modbus/TCP 502, S7comm 102, EtherNet/IP 44818, DNP3 20000.
