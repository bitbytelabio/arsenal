# Tool Default Values

- `js-reverse_list_network_requests`: Inspect the first page of default results first; paginate only if insufficient
- `js-reverse_search_in_sources`: Defaults to `excludeMinified=true`
- `js-reverse_get_script_source`: Read small snippets only; for full source code, use `js-reverse_save_script_source` instead
- `js-reverse_break_on_xhr`: Enter only URL fragments that hit reliably
- `js-reverse_get_paused_info`: Inspect `frameIndex=0` first by default
